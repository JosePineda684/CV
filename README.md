# CV

My name is Jose Maria Pineda. I am a current physics master's student at
California State University, Fullerton and research assistant at the Nicholas
and Lee Begovich Center for Gravitational-Wave Physics and Astronomy in their
numerical-relativity research group. Working with Professor Geoffrey Lovelace, I
use SpECTRE, a next-generation, open-source numerical-relativity code in
development, with the goal of modeling binary black holes with high accuracy and
reasonable computational cost for next generation gravitational wave detectors.
My current project extends previous work by Chen et al. (arXiv:2108.02331) to
SpECTRE. This work has demonstrates how an improved choice of coordinates can
greatly increase the efficiency in modeling nearly extremal black holes using
SpECTRE's predecessor, the Spectral Einstein Code (SpEC).

it) CV, along with relevant materials.
